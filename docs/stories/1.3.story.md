## Story

**Como** usuário de qualquer perfil,  
**quero** entrar no sistema com meu perfil e receber mensagens de erro compreensíveis,  
**para** usar apenas o que meu perfil permite, com meus dados protegidos.

## Escopo

### Incluído

- Esquema PostgreSQL versionado com Flyway (todas as tabelas, constraint de exclusão e trigger de auditoria imutável).
- Spring Security: perfis SOLICITANTE/RESPONSAVEL/ADMINISTRADOR, login por formulário com sessão e CSRF, HTTP Basic para API, BCrypt.
- Respostas 401/403 em JSON, sem `WWW-Authenticate`; cabeçalhos CSP, X-Frame-Options e nosniff.
- Gestão de usuários pelo Administrador (criar, alterar perfil, desativar; nada é apagado).
- Auditoria gravada na mesma transação (Propagation.MANDATORY).
- Tratamento de erros RFC 7807 com mensagens em português e código de rastreio para erro interno.
- Infraestrutura de teste: PostgreSQL real (Testcontainers), relógio controlável e cliente HTTP caixa-preta.

### Fora de escopo

- Provedor de identidade institucional (DP-019: autenticação própria).
- Escopo do Responsável por recurso (evolução).

## Critérios de aceite

### AC1 — Login por perfil

**DADO** um usuário ativo com senha correta  
**QUANDO** autenticar  
**ENTÃO** recebe seu perfil e nunca o hash da senha.

### AC2 — Acesso anônimo negado

**DADO** qualquer endpoint de /api exceto o login  
**QUANDO** for chamado sem credenciais  
**ENTÃO** recebe 401/403 com mensagem em português.

### AC3 — Matriz de perfis

**DADO** um perfil sem permissão para a operação  
**QUANDO** chamar o endpoint  
**ENTÃO** recebe 403 ACESSO_NEGADO.

### AC4 — Sessão web protegida

**DADO** uma sessão iniciada pelo formulário  
**QUANDO** fizer escrita sem o token CSRF  
**ENTÃO** recebe 403 CSRF_INVALIDO; com o token, a escrita é aceita; após logout, a sessão não vale mais.

### AC5 — Gestão de usuários

**DADO** o Administrador  
**QUANDO** criar, alterar ou desativar usuário  
**ENTÃO** a operação é auditada; login duplicado dá 409; usuário desativado não autentica; o Administrador não se desativa.

### AC6 — Erros compreensíveis

**DADO** entrada inválida ou erro interno  
**QUANDO** a API responder  
**ENTÃO** usa ProblemDetail em português, sem stack trace.
