## Story

**Como** equipe de desenvolvimento,  
**quero** que todo push e pull request rode build, testes, cobertura e análise estática,  
**para** impedir que código sem verificação chegue à main (limitador de nota: pipeline ausente).

## Rastreabilidade

| Tipo | Referência |
|---|---|
| Requisitos | RNF-013 (testabilidade), RNF-014 (manutenibilidade) |
| ADR | ADR-009 |
| Enunciado | CI e análise estática: GitHub Actions em PR, JaCoCo, SonarCloud; metas 80% linhas / 70% branches / 0 críticos |
| Gate 1.1 | PROC-001 e CFG-001 |

## Escopo

### Incluído

- Workflow `.github/workflows/ci.yml` em todo push, PR para `main` e execução manual.
- Gate JaCoCo no `mvn verify`: 80% de linhas e 70% de branches no sistema inteiro (classe `main` excluída).
- SonarCloud via `sonar-maven-plugin`, restrito a `src/main` e `src/test` (o framework AIOX versionado fica fora da análise); passo pulado se o segredo `SONAR_TOKEN` não existir.
- Maven Wrapper (`./mvnw`) para builds reprodutíveis.
- Relatórios de teste e cobertura publicados como artefato e resumo da cobertura na página do run.

### Fora de escopo

- Criação da organização/projeto no SonarCloud e do segredo `SONAR_TOKEN` (ação manual do dono do repositório).
- Configuração da proteção da branch `main` (ação manual do dono do repositório; ver README).

## Critérios de aceite

### AC1 — Pipeline em todo PR

**DADO** um push ou pull request para a main  
**QUANDO** o GitHub Actions executar  
**ENTÃO** compila, roda todos os testes e publica os relatórios.

### AC2 — Gate de cobertura

**DADO** cobertura abaixo de 80% de linhas ou 70% de branches  
**QUANDO** `./mvnw verify` executar  
**ENTÃO** o build falha com a regra violada.

### AC3 — Sonar apenas no código do projeto

**DADO** o segredo SONAR_TOKEN configurado  
**QUANDO** o pipeline executar  
**ENTÃO** a análise considera apenas `src/main` e `src/test`.

### AC4 — Pipeline resiliente sem Sonar

**DADO** o segredo ausente  
**QUANDO** o pipeline executar  
**ENTÃO** o passo do Sonar é pulado e o restante roda normalmente.
