# ADR-009 — Estrategia de testabilidade e TDD

**Status:** Proposta; metas/limiares de qualidade pendentes.  
**Data:** 2026-10-20

## Contexto

O projeto exige TDD e define JUnit 5, Testcontainers, WireMock, JaCoCo, SonarCloud, GitHub Actions e JMeter como referencias. RNF-013 pede comportamentos observaveis. Integridade concorrente requer persistencia real, nao apenas mocks.

## Problema arquitetural

Como permitir testes rapidos de regra e evidencia real de fronteiras de persistencia/externas?

## Alternativas consideradas

- **A — Separar dominio/casos de uso de adaptadores e exercitar piramide de teste (proposta):** unitarios isolados, integracao real, HTTP/aceitacao e carga.
- **B — Testar somente unitarios com mocks:** rapido, mas nao verifica transacoes, constraints, autorizacao efetiva ou concorrencia.
- **C — Testar somente de ponta a ponta:** cobre fluxo amplo, mas e lento e localiza falhas com dificuldade.

## Decisao proposta

Usar TDD Red-Green-Refactor com JUnit 5: unitarios para intervalos, autorizacao, estados e agregacoes; integracao com Testcontainers para persistencia/transacoes/concorrencia; WireMock somente para integracoes HTTP aprovadas; teste de fluxo/HTTP para contratos que forem definidos; JMeter para carga quando metas existirem. JaCoCo/SonarCloud e GitHub Actions produzem evidencias depois que equipe definir gates. Mocks nao substituem integracao real.

## Justificativa

Corresponde a diretrizes academicas e aos limites modulares propostos. Mantem feedback rapido sem omitir riscos de integridade.

## Consequencias positivas

- Regras criticas entram no ciclo RED antes do codigo.
- Evidencia real para banco/concorrrencia e integracao externa.

## Consequencias negativas

- Suite de integracao pode levar mais tempo e exigir ambiente de containers.
- Limiares de cobertura, carga e analise estatica ainda nao estao acordados.

## Riscos

Mocks podem tornar testes tautologicos; mitigacao: mapear RF/CA para teste unitario e de integracao correto, priorizando RF-008/RNF-004 e transicoes/auditoria.
